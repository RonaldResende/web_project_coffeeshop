# Triple Espresso
web_project_coffeeshop
O projeto foi criado com o intuito de promover aos clientes uma agenda mais definida, marcar uma hora para tomar um café é uma excelente escolha de lugar para uma reunião de negócios e projetos e também para um lazer diário e aconchegante. Usamos as bases da tecnologia para criar, como por exemplo, HTML e CSS de base.
